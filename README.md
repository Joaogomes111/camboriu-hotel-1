# Camboriú Hotel LP

Landing page estática para o Camboriú Hotel, em Balneário Camboriú. O site
substitui a presença em WordPress por uma página simples, rápida e focada em
reserva direta pelo WhatsApp.

## Conteúdo

- capa com chamada principal e botão de reserva
- acomodações do hotel
- comodidades dos quartos
- galeria com fotos reais
- localização, contato e redes sociais

## Comandos

```bash
npm run dev
npm run build
npm test
```
